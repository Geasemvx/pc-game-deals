PC Game Deals
A lightweight web application built as part of a developer entry assessment. This project demonstrates core JavaScript fundamentals through a collection of PC game deals, including filtering sale items, calculating discounts, finding the cheapest game, and implementing case-insensitive search functionality.

Features
Display a list of PC game deals
Highlight games currently on sale
Show normal and sale prices
Calculate discount percentages
Find the cheapest available game
Search game titles case-insensitively
Responsive and user-friendly interface
Built with vanilla JavaScript, HTML, and CSS
Tech Stack
HTML5
CSS3
JavaScript (ES6)

Core Functions
The project includes solutions for the following programming tasks:

Filter Games on Sale
Returns only games whose sale price is lower than their normal price.

Calculate Discount Percentage
Computes the percentage discount for a given game.

Find the Cheapest Game
Identifies the game with the lowest sale price.

Search Games
Performs a case-insensitive search on game titles.

Assumptions
A game is considered on sale when salePrice < normalPrice.
Prices supplied in the assessment data are considered valid.
Search functionality should be case-insensitive.
Discount percentages are rounded to the nearest whole number.
